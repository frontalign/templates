# FrontAlign Agency Starter

A modern, responsive agency starter template built with FrontAlign.

Designed for freelancers, studios, agencies, consultants, and creative professionals who want a clean foundation for their next project.

## Features

* Responsive landing page
* Modern hero section
* Business statistics section
* Services section
* Contact page
* Services page
* Privacy Policy page
* Terms & Conditions page
* Built with FrontAlign
* Motion-powered reveal animations
* Clean and extensible structure

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
